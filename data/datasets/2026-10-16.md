## [leczhang/recenter-personalization](https://huggingface.co/datasets/leczhang/recenter-personalization) · A

该数据集围绕LLM个性化三阶段流水线（用户属性提取、属性-提示相关性匹配、个性化回复生成）收集了基于WildChat真实用户和CUPID/PrefEval/PersonaLens合成用户的细粒度人类标注（5,949+11,919+1,101条判断），每阶段附5个LLM的输出与判断，可直接用于个体属性建模与个性化研究。

用途（推断）：可用于（1）从个体对话历史中提取稳定属性（偏好、风格、背景）并以人类多数投票为真值训练/评估属性抽取器；（2）研究个体属性与新提示的相关性匹配，作为个性化检索或条件生成中的标签监督；（3）以人类偏好的1–5分对比个性化vs通用回复，训练或评测个性化回复奖励模型/用户模拟器。需自行确认属性编码体系是否匹配目标研究，并验证跨用户泛化能力。

依据：证据(metadata)显示任务被明确定义为individual-level personalization，标签字段(metadata,card)含人类多数投票的ground truth与confidence；(card)说明user_id为WildChat的hashed_ip或合成persona id，是稳定个体标识；(paper)摘要确认研究目的是评估从真实用户对话中提取、选择、整合用户信息的效果，与个体行为/偏好建模直接对应。三阶段判断中Stage 1属性准确性、Stage 2属性-提示相关性、Stage 3回复个性化偏好评分为个体建模提供端到端监督；WildChat对话提供个体交互序列（虽无时间戳，但有序）。属于直接证据，非关键词匹配。

- 来源：混合
- 个体ID：WildChat hashed_ip 作为真实用户ID；合成用户用 persona id；在 stage1/stage2/stage3 items 中以 user_id 出现
- 时间：未知
- 标签：Stage 1: ok/unsure/bad 三档属性判断（3标注者×属性）；Stage 2: relevant/not relevant 三标注者判断；Stage 3: 1–5分偏好评分（1=偏好通用回复，5=偏多个性化回复），含 display_assignment
- 许可：cc-by-sa-4.0
- 限制：Stage 1只覆盖77个用户（47 WildChat + 30合成），Stage 2/3涉及41个LIMA提示×164用户对，个体覆盖规模有限
- 限制：WildChat对话已剥离时间戳与IP派生字段，无法分析纵向时间行为
- 限制：WildChat原始数据为ODC-BY许可，使用需遵守其条款；合成PersonaLens为CC BY-NC 4.0
- 限制：Stage 3中只有item_index<80的582条item有人类标注，其余仅有LLM判断，限制了监督训练规模

## [DJ-Research/Sotopia-artifacts](https://huggingface.co/datasets/DJ-Research/Sotopia-artifacts) · A

Sotopia 社交模拟项目生成的多配置数据集，包含40个合成智能体人格档案（含Big Five/MBTI/Schwartz价值观/决策风格）、90+360个社会场景配置、450个环境-智能体组合、120个双人关系档案，以及21,333条多轮社交对话episodes（含对话消息、推理与奖励）。

用途（推断）：个体方向：利用agent_profiles中40个带Big Five/MBTI/道德价值/决策方式字段的合成角色，构建人格条件化的个体行为/偏好模拟器或人格一致性评测基准。交互方向：直接消费episodes配置中的有序messages（21,333条）与reasoning、rewards，分析多轮协商/社交对话中角色人格与论点风格如何影响交互轨迹，并复现社会交互模拟评测。群体方向：通过env_agent_combos与environment_profiles联合分析同一场景下多智能体组合的任务完成差异，研究群体决策与目标冲突。

依据：episodes配置提供了超过两万条带推理和奖励的多智能体有序对话，直接对应社会交互/协商研究的核心任务（证据：metadata.cardData config episodes features messages/reasoning/rewards，num_examples=21333）。agent_profiles以可链接的pk为ID并附带Big Five、MBTI、Schwartz价值观、决策风格等结构化人格标签，支持个体行为与用户模拟（证据：metadata cardData agent_profeatures；fields 0–15；sample 行0–2）。relationship_profiles定义带背景故事的二元关系、env_agent_combos将多个agent绑入同一scenario，支持群体/关系层面分析（证据：metadata cardData relationship_profiles / env_agent_combos）。判断为A级直接支持，数据已公开（gated=false）且无需申请即可下载使用。

- 来源：合成
- 个体ID：agent_profiles与episodes等配置均含字符串主键pk，可作为agent稳定标识跨配置链接；episodes中agents字段以可解析字符串记录参与agent，env_agent_combos.agent_ids为字符串列表
- 时间：未知
- 标签：个体层面：big_five、mbti、moral_values、schwartz_personal_values、decision_making_style、personality_and_values、secret、public_info；交互/群体层面：environment_profiles.task_type、relationship_profiles.relationship（int）、episodes.rewards、episodes.tag
- 许可：未知
- 限制：agent_profiles仅40个角色，规模有限，跨角色泛化需额外验证
- 限制：environment_profiles_synthetic中pk字段为null，无法以主键关联该子集
- 限制：messages/reasoning/rewards以字符串形式存储，需解析后才可逐轮使用
- 限制：agent_profiles.model_id在样本中为空字符串，使用具体模型做归因时需自行确认
- 限制：数据全部为合成角色，非真实用户行为，社会迁移需在论文层面说明外推限制

## [irlab-udc/erisk-depression-personas](https://huggingface.co/datasets/irlab-udc/erisk-depression-personas) · A

面向116位eRisk抑郁严重度任务Reddit用户的LLM生成persona数据集，含两种persona变体（P仅基于行为画像；POWER基于画像+写作样本并带写作风格与情感词汇校准）及对应的BDI-II自测量表答案、分数与严重度等级。

用途（推断）：用于个体层面的用户模拟与心理健康行为建模：以persona作为LLM系统提示模拟特定抑郁严重度个体的Reddit回复，评估模拟在情感词汇、写作风格上与真人回复的一致性；可作为个体行为/心理状态条件生成、抑郁严重度与语言表达关联研究、以及persona归纳方法对比（P vs. POWER）的资源；亦可作为agent式社会模拟中个体心理画像初始化模块的参考。需逐用户验证模拟回复的情感保真度与persona忠实度，并探索BDI分数与persona内容特征的统计关联。

依据：数据直接以116名具稳定伪ID的个体为粒度，分别携带行为画像衍生文本与BDI-II量化的心理状态标签，与individual方向中"个体行为、偏好、人格、认知、心理状态及用户模拟"高度对齐；persona专为大语言模型用户模拟设计，覆盖从最小到重度四级抑郁标签，可作为心理条件用户模拟的训练/评估素材。interaction方向仅作为间接可延伸（persona用于生成Reddit回复涉及交互），但数据集本身不含交互日志；group/society因仅116人且无网络结构而关联较弱。access gated=true且需人工审批，加之含敏感健康信息，标记为conditional。

- 来源：混合
- 个体ID：伪匿名id字段（user_XXXX格式），每行对应一名Reddit用户，三个子集行序一致，可按id跨子集对齐
- 时间：原始eRisk写作时间跨度2005-06至2020-10；数据集本身不包含每条persona或每次回复的时间戳
- 标签：golden子集含21项BDI-II答案（含16/18项a/b方向）、0–63的bdi_score与四级bdi_severity（minimal/mild/moderate/severe），为用户自报量表结果；POWER persona内嵌Ekman七基本情绪占比
- 许可：other
- 限制：数据集gated=true，需在Hugging Face填写表单并经作者人工审批方可访问
- 限制：包含自报抑郁严重度等敏感健康信息，须遵守禁止识别/联系真人、禁止临床诊断等使用条款
- 限制：persona由LLM生成（Llama 3.3 70B + Phi-4 critic），可能含与用户实际行为不符的细节
- 限制：样本仅限参与eRisk的英语Reddit用户，不具代表性
- 限制：BDI为单次自报量表，非临床诊断
- 限制：字段预览未获取，具体字段结构以golden/personas_p/personas_power三个JSONL为准
- 限制：数据卡超过阅读上限，仅检查开头；信息可能不完整。
- 限制：字段预览未获取（可能需申请或不支持预览）；未确认的属性标为未知。

## [StrataSynth/stratasynth-termination-negotiations-pt-br](https://huggingface.co/datasets/StrataSynth/stratasynth-termination-negotiations-pt-br) · B

合成数据：100段、1731轮巴西葡萄牙语职场解雇谈判对话，每轮标注说话人角色（雇主/HR vs 员工）、心理原型、认知意图（intent→goal→communication_act）以及情绪维度（tension、connection、vulnerability），是与法国版的跨文化配对数据集。

用途（推断）：可用于谈判交互动力学建模（结合言语行为、认知意图与情绪轨迹分析权力不对称下的话轮演变）、基于心理测量条件的智能体/用户模拟（以archetype与Big Five分布驱动对话策略），以及巴西—法国跨文化职场沟通风格比较（前提是同时获取法国版并对齐schema）。所有迁移需用真实语料或人类评估验证合成结论的外部效度。

依据：数据卡明确为两人对话、带有认知意图链与情绪连续标注，结构上直接支撑交互方向谈判行为分析；persona由国家心理测量分布采样，可驱动individual方向的agent模拟；与法国版配对提供了society方向跨文化比较的实验条件。但全部为合成数据，缺少真实个体ID和时间戳，外部效度需自行验证，因此评为B。

- 来源：合成
- 个体ID：无真实个体标识；conversation_id为合成对话编号，persona_a/persona_b为角色标签而非真实用户ID，原型（archetype）由心理测量分布采样生成
- 时间：无真实时间戳；仅有turn_index（0-起整数）和turn_id（t001…）表示话轮顺序，arc_type描述叙事弧类型，但无绝对时间或纵向追踪
- 标签：每轮标注：intent（认知意图）、goal（说话人目标）、communication_act（言语行为，如deflection、reassurance、boundary_setting等）、tension/connection/vulnerability（0–1连续情绪）、is_noisy（是否含注入噪声）、archetype（说话人原型）、arc_type（对话叙事弧）
- 许可：cc-by-4.0
- 限制：全部为合成数据，研究结论需真实语料验证
- 限制：仅100段对话、1731轮，样本量有限
- 限制：无真实时间戳或纵向追踪，仅turn级顺序信息
- 限制：对话语言为葡萄牙语，NLP处理需葡萄牙语工具链
- 限制：跨文化比较需同时获取法国版配对数据集并确认schema一致

## [Neph0s/CoSER](https://huggingface.co/datasets/Neph0s/CoSER) · B

CoSER 是一个面向角色扮演 LLM 的高质量数据集，从 771 部知名小说中提取约 17,966 个角色的多轮多角色对话，包含角色档案、对话内容、情节摘要、角色经历、内心想法和动作描写，数据为英文、MIT 许可、非 gated。

用途（推断）：可用于研究虚构角色的个体行为与人格/认知状态建模（基于角色档案、经历与内心想法字段）；可用于研究多角色对话中的人际交互、协商与关系变化（基于多轮多角色对话、内部想法与动作字段）；可用于研究小说场景中的群体互动模式（基于场景级对话与背景信息）。具体任务可包括对话风格分析、社会规范在叙事中的体现方式、角色心理状态推断等，但需将文学化表达迁移到一般化的社会行为假设时验证迁移性。

依据：数据包含结构化的角色档案、经历、内部想法与多角色对话，可直接支撑'个体'方向的人格/心理状态与角色模拟研究，以及'交互'方向的多轮对话与关系动态分析；多角色同场景对话也可支持'群体'方向的小群体行为观察。判断为 B 而非 A 的原因是数据来源为文学小说，对话并非真实人类互动记录，而是经过创作加工的叙事性内容，迁移到真实社会行为研究时需要额外验证其代表性。此外，metadata 与 paper 未在预览中提供字段级样本细节，部分结论依赖 card 与 paper 的描述性证据。

- 来源：合成
- 个体ID：包含约 17,966 个角色，按小说组织，full 目录以书名为文件名，每个角色在各自 JSON 中应有独立条目；当前预览未提供字段样本以确认是否存在稳定跨书角色 ID。
- 时间：无显式时间戳字段；对话以叙事顺序组织，情节摘要与角色经历可能包含时间线信息（未在预览中确认字段细节）。
- 标签：包含角色档案（character profiles）、对话（dialogues）、情节摘要（plot summaries）、角色经历（character experiences）、内心想法（thoughts）、动作描写（actions）、对话背景（conversation backgrounds），以及安全相关的 truncated_for_safety_concerns 标记。
- 许可：mit
- 限制：数据来源于文学小说，并非真实人类交互记录，迁移到真实社会行为研究需额外验证
- 限制：默认 split 为 test（200 样本），完整数据需从 full 目录或 GitHub 获取
- 限制：Hugging Face 预览查看器可能无法完整展示复杂 JSON 结构，建议参考 GitHub 示例
- 限制：card 未提供字段级样本，预览未能获取以核实具体字段结构
- 限制：已对 110 条对话进行截断、移除 602 条消息用于安全处理
- 限制：字段预览未获取（可能需申请或不支持预览）；未确认的属性标为未知。
